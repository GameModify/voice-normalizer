# VoiceNormalizer

Выравнивание громкости выбранных участников Discord для **BetterDiscord**. Автор: **-$erent*-** ([GameModify](https://github.com/GameModify)). Версия: **1.3.0-beta.1**.

## Возможности

- Галочка «Выравнивать громкость голоса» через ПКМ на участнике.
- Сохранение выбранных **user ID** после перезапуска Discord, выключения плагина и выхода из канала.
- Автоматическое возобновление при появлении выбранного участника в текущем соединении. Средний уровень калибруется заново после смены соединения или возвращения участника.
- Усиление тихой речи, ослабление громкой, удержание среднего в паузах. Короткие события не меняют среднее, но громкие пики могут временно ослабляться.
- Режим «Все в голосовом канале», включая новых участников, с исключениями по user ID. Режим «Выбранных людей» сохраняет ручной список.
- Режим «Только приглушать громкое»: коррекция никогда не поднимает громкость выше исходной настройки Discord.
- Профили «Мягкий», «Баланс», «Агрессивный» доступны кнопками и через ПКМ. Для каждого человека можно выбрать свой профиль либо «Как у всех». Настраиваются целевой уровень, пределы усиления/ослабления и скорости регулировки. Параметры сохраняются автоматически.
- Понятные статусы: ожидание речи, обучение, активное выравнивание. Сброс обучения доступен в карточке и ПКМ.
- Настройки на русском и английском: автоматически по языку Discord или ручной выбор.
- Стабильный список: включение сверху, управление выбранными ниже. Кнопки профилей не открывают системный select; обновления индикаторов не пересоздают строки. Технические параметры и диагностика находятся в свёрнутом разделе «Дополнительно».
- Восстановление исходной громкости при отключении. Ручной ползунок задаёт новую базу; нулевая громкость не повышается автоматически.

## Установка

1. Установите [BetterDiscord](https://betterdiscord.app/).
2. Скопируйте **только** `VoiceNormalizer.plugin.js` в `%APPDATA%\BetterDiscord\plugins` на Windows. Папку можно открыть через Open Plugins Folder в BetterDiscord.
3. Включите VoiceNormalizer, поставьте галочку у нужного участника через ПКМ.

Выбрать пользователя можно вне звонка. Снять галочку можно через ПКМ или карточку сохранённого пользователя в настройках, даже когда его нет в канале. **«Отключить для всех» очищает сохранённый список.** Выключение самого плагина в BetterDiscord список сохраняет.

User ID хранятся локально под ключом `targets`, параметры — под ключом `settings`, режимы, язык, исключения и профили участников — под ключом `preferences` в `BdApi.Data` плагина VoiceNormalizer. Аудиозаписи, история измерений и средние уровни на диск не сохраняются. Обновление с 1.2.0 сохраняет профили; старые галочки нужно поставить один раз, поскольку прежняя версия их не записывала.

## Ограничения

Плагин считывает статистику входящего аудио и меняет локальную громкость примерно раз в 100 мс. Это **не сэмпловый лимитер**: начало резкого крика может пройти до регулировки. RTP audioLevel — относительный уровень, не LUFS и не положение ползунка. Статистика не отличает достоверно речь от всех посторонних звуков.

Внутренние API Discord могут измениться. Тесты с имитацией Discord не заменяют прослушивание звонка. Совместимость с другими регуляторами, включая BetterVolume, требует ручной проверки. После аварийного завершения Discord восстановление исходной громкости не гарантируется.

## Разработка

Нужен **Node.js 22+**. Исходники — в `src/`, `VoiceNormalizer.plugin.js` генерируется esbuild. Зависимости нужны только для разработки; собранный плагин работает одним файлом.

```bash
npm ci
npm run format
npm run build
npm run check
npm test
```

Тесты запускаются **на готовой сборке**; `npm test` не пересобирает плагин. В CI проверяется соответствие сборки исходникам, затем выполняется полный набор тестов. Не нужно прогонять его после каждой функции.

Код разделён на локализацию (`src/i18n.js`), режимы и настройки пользователей (`src/preferences.js`), панель настроек (`src/ui/settings-panel.js`), контроллер Discord (`src/index.js`), расчёт усиления и детектор активности (`src/audio/`), профили и проверку параметров (`src/audio/settings.js`), элементы настроек (`src/ui/`). В 1.2.1 исходники синхронизированы с рабочей сборкой 1.2.0 от 19 октября, включая отсутствовавшие модули настроек.

Статус — beta. [Правила BetterDiscord](https://docs.betterdiscord.app/plugins/publishing/guidelines) требуют публичного GitHub-репозитория и очистки изменений при отключении; английский интерфейс добавлен. В правилах есть ограничение на автоматически сгенерированные плагины, включая AI. Проект разработан с участием владельца, помощью ChatGPT/Codex, проверкой кода и тестированием. Применимость критерия AI-generated к такому процессу и решение о приёме следует уточнить у команды каталога.

Лицензия пока не выбрана. Публикация репозитория сама по себе не задаёт лицензию на повторное использование кода.
