# VoiceNormalizer

Экспериментальный плагин для **BetterDiscord**, который автоматически выравнивает громкость выбранных участников голосового чата.

> **Статус:** `1.0.7-alpha`. Это тестовая версия, а не готовый аудиолимитер. Изменения громкости зависят от статистики и внутренних API Discord, которые могут изменяться.

## Возможности

- Выбор отдельных участников через контекстное меню Discord.
- Адаптивное ослабление громкой речи и усиление тихой.
- Скользящее среднее по речевым измерениям и сохранение громкости в паузах.
- Индикация текущего уровня, среднего и коэффициента коррекции в меню и настройках.
- Восстановление исходной громкости при отключении обработки.
- Диагностика связи SSRC с участниками и записи громкости.

## Установка

1. Установите [BetterDiscord](https://betterdiscord.app/).
2. Скачайте [VoiceNormalizer.plugin.js](./VoiceNormalizer.plugin.js) (через **Raw** → сохранить как файл).
3. Поместите файл в `%APPDATA%\BetterDiscord\plugins` (Windows) или в папку плагинов BetterDiscord на вашей ОС.
4. Включите **VoiceNormalizer** в настройках BetterDiscord и подключитесь к голосовому каналу.
5. Нажмите ПКМ на участнике и выберите **«Выравнивать громкость голоса»**.

**Важно:** сначала проверяйте обработку на комфортной громкости. Внезапные пики звука могут проходить до срабатывания регулировки. Плагин **не выполняет аудиообработку по отдельным сэмплам** и не гарантирует защиту слуха от криков.

## Как это работает

Плагин считывает статистику входящих аудиопотоков из медиадвижка Discord, связывает SSRC с участником и корректирует его локальную громкость через внутренний API Discord. Средняя громкость вычисляется по обнаруженной речи и удерживается во время пауз. Это экспериментальная реализация автоматической регулировки усиления, а не полноценный DSP-компрессор.

Существующий ползунок Discord может не перерисовываться в реальном времени; актуальную коррекцию можно посмотреть на индикаторах VoiceNormalizer. Ручное изменение громкости пользователя принимается за новую исходную настройку.


## Для разработчиков

Исходный код находится в `src/`; файл `VoiceNormalizer.plugin.js` в корне **генерируется сборкой**. Не редактируйте генерируемый файл напрямую.

```bash
npm install
npm run build
npm run check
npm test
```

Нужен Node.js 20+. Сборка использует esbuild и создаёт один файл для BetterDiscord. ESLint проверяет исходники, Prettier поддерживает единое оформление. Перед Pull Request убедитесь, что пересобранный `VoiceNormalizer.plugin.js` включён в изменения, а четыре регрессионных теста проходят.

## Разработка и тесты

Требуется **Node.js 20+**. Внешних npm-зависимостей нет.

```bash
npm test
```

Тесты находятся в [`tests/`](./tests/): имитируют медиадвижок Discord, SSRC, изменения громкости, паузы и меню. Они **не подтверждают** работу внутри настоящего звонка; после изменений нужна ручная проверка в Discord. GitHub Actions автоматически запускает тесты для push и Pull Request.
