**Тихая речь становится громче, громкая — тише.** Плагин запоминает обычный голос каждого участника и применяет временную коррекцию отдельно от пользовательского ползунка Discord.

## Быстрый старт

1. Установите [BetterDiscord](https://betterdiscord.app/) для настольного Discord.
2. Скачайте **[VoiceNormalizer.plugin.js](https://github.com/GameModify/voice-normalizer/releases/latest/download/VoiceNormalizer.plugin.js)**.
3. Откройте папку плагинов из настроек BetterDiscord и положите туда файл. На Windows: `%APPDATA%\BetterDiscord\plugins`.
4. Включите VoiceNormalizer. Выставьте человеку комфортную громкость при его обычной речи.
5. Нажмите на него ПКМ → **«Выравнивать громкость голоса»**. Дайте ему примерно две секунды обычной речи для обучения.

Для установки достаточно одного файла. Node.js и архивы **Source code** не нужны. Рядом с файлом релиза опубликованы `LICENSE` и `SHA256SUMS.txt`.

Инструкция рассчитана на Windows. Интернет нужен для скачивания и голосового соединения Discord; отдельного сервера у плагина нет.

## Возможности

- **Выбранные люди или весь канал.** В настройках можно включить **«Всех в голосовом канале»** — новые участники подключатся автоматически. Отдельных людей можно исключить; собственный голос не обрабатывается.
- **Ручная громкость остаётся под вашим контролем.** Автокоррекция не двигает ползунок. Изменение ручной громкости задаёт новую базу, сохраняя обучение.
- **Плавное восстановление.** После громкой фразы громкость возвращается постепенно во время речи. Паузы не повышают громкость, значение 0 сохраняет mute.
- **Выбор сохраняется.** Участники, исключения и профили остаются после перезапуска Discord. Обучение обычному голосу начинается заново после перезапуска плагина.

В режиме **«Только приглушать громкое»** усиление выше ручной базы отключено. При отключении обработки восстанавливается последняя ручная громкость.

## Профили

Для начала подойдёт **«Баланс»**.

| Профиль | Коэффициент коррекции | Для чего |
| --- | --- | --- |
| Мягкий | ×0,65–1,3 | Небольшие перепады, плавная реакция |
| Баланс | ×0,45–2 | Повседневные разговоры |
| Агрессивный | ×0,35–2 | Более быстрая реакция и сильное приглушение |

Это множители внутренней громкости относительно ручной базы, а не положение ползунка и не измеренные децибелы. Максимальное усиление у «Баланса» и «Агрессивного» одинаковое; отличаются сила коррекции и скорость реакции.

<details>
<summary><strong>Индивидуальные профили и точные настройки</strong></summary>

**Как у всех** использует общие параметры. Индивидуальный профиль заменяет их для одного человека.

Списки участников раскрываются по нажатию. Профиль находится в **«Индивидуальных настройках»** карточки, точные параметры, язык и диагностика — в **«Дополнительно»**.

Если начальное обучение пришлось только на шёпот или крик, нажмите **«Сбросить обучение»**, когда человек говорит обычно. Выбор участника и профиль сохранятся.

[Подробное описание настроек](./docs/SETTINGS.md).

## Данные и обновление

Настройки хранятся локально в `VoiceNormalizer.config.json` рядом с плагином. На Windows: **`%APPDATA%\BetterDiscord\plugins\VoiceNormalizer.config.json`**. В файле находятся пользовательские ID и параметры обработки.

Для обновления замените `VoiceNormalizer.plugin.js` файлом из [последнего релиза](https://github.com/GameModify/voice-normalizer/releases/latest). BetterDiscord перезагрузит плагин; выбранные участники, режимы и профили сохранятся.

<details>
<summary><strong>Резервная копия, переход с 1.3 и откат</strong></summary>

Перед обновлением можно скопировать конфигурацию в отдельную папку. Не прикладывайте её к публичному issue целиком.

При переходе с 1.3 прежняя общая цель громкости больше не используется: 1.4 обучается на обычной речи каждого человека. Выбор участников и остальные поддерживаемые настройки сохраняются; после обновления нужно короткое обучение.

Для отката отключите плагин, верните файл из [нужного релиза](https://github.com/GameModify/voice-normalizer/releases) и включите его. Резервную конфигурацию восстанавливайте при закрытом Discord.

</details>

## Ограничения

Плагин регулирует громкость по статистике Discord, не обрабатывая аудиосэмплы: начало резкого пика может пройти до приглушения. Внутренние методы Discord могут меняться; при недоступном независимом управлении звуком обработка не включается.

Совместимость с BetterVolume при повышенной громкости отдельно не подтверждена.
