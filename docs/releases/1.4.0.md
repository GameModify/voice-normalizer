# VoiceNormalizer 1.4.0

Voice leveling now preserves your manual Discord volume. Temporary correction is applied separately to playback.

## Changes

- Learns each person's ordinary speech in about two seconds instead of using one global target.
- Boosts confirmed quiet speech, including levels below the previous speech gate.
- Reduces loud speech and recovers toward normal volume smoothly, without raising volume in pauses.
- Preserves voice learning when you adjust the manual slider.
- Fixes near-silent playback caused by different read/write volume scales in desktop Discord.
- Restores the latest manual baseline when processing stops.

## Install or update

Requires desktop Discord with [BetterDiscord](https://betterdiscord.app/). Download [VoiceNormalizer.plugin.js](https://github.com/GameModify/voice-normalizer/releases/download/v1.4.0/VoiceNormalizer.plugin.js), place it in the BetterDiscord plugins folder, and enable it. On Windows: `%APPDATA%\BetterDiscord\plugins`.

To update, replace the existing plugin file. Participant selections, profiles, and supported preferences are retained. The old global target is no longer used; allow a short period of normal speech for fresh calibration.

Only the plugin file is needed to run. **Source code** archives are for development. MIT terms are embedded in the plugin and provided in `LICENSE`; `SHA256SUMS.txt` lists download checksums. [Update, backup, and rollback instructions](https://github.com/GameModify/voice-normalizer/blob/v1.4.0/README.en.md#updates-and-data).

## Validation and limitations

The final build passes 52 automated tests, lint, formatting, generated-build validation, and an isolated start/stop/persistence check of the staged plugin. Voice operation has also been checked by listening in Discord.

This is a statistics-based leveler, not an instant audio limiter: the start of a sudden peak may pass before correction. Elevated-volume BetterVolume compatibility is not separately confirmed. Discord's internal APIs can change.

## По-русски

Автокоррекция теперь применяется отдельно от ручной громкости Discord. Плагин обучается на обычной речи каждого человека, усиливает тихие фразы и плавно восстанавливает громкость после громких. Ручная смена громкости сохраняет обучение. Исправлено пропадание звука из-за разных шкал аудиоинтерфейса.

Для установки скачайте файл плагина из Assets и положите в папку плагинов BetterDiscord. Для обновления замените старый файл; выбранные участники и поддерживаемые настройки сохранятся. После обновления дайте человеку примерно две секунды обычной речи.

Плагин не является мгновенным лимитером. Совместимость с BetterVolume при повышенной громкости отдельно не подтверждена. [Установка, резервная копия и откат](https://github.com/GameModify/voice-normalizer/blob/v1.4.0/README.md#обновление-и-данные).
