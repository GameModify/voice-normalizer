# Дорожная карта

Текущая стабильная версия — **1.3.0**. Основной набор функций MVP завершён.

## Готово

- Сохранение участников по user ID, индивидуальных профилей и исключений.
- Ручной выбор людей и режим для всего голосового канала, включая новых участников.
- Усиление тихой речи, приглушение громкой и режим только приглушения.
- Три профиля, общие ручные параметры и сброс обучения.
- Плавное восстановление громкости во время речи, удержание в паузах и повторное подтверждение речи после пропуска статистики.
- Сворачиваемые списки участников, статусы и русский/английский интерфейс.
- Сборка в один файл, автоматические проверки и тесты готового плагина.

## Проверено в Discord

Пользователь подтвердил сохранение выбора, режим для всех, переключение профилей, обучение и включение/отключение участников. После доработки сглаживания результат прослушивания оценён как хороший. Смена канала и ручное изменение громкости также проверены: новая громкость становится базой, обучение начинается заново.

Стабильная версия сохраняет алгоритм проверенной beta.7. Ранее сохранение после перезапуска было проверено; отдельная повторная проверка перезапуска при подготовке 1.3.0 не проводилась. Полная совместимость с BetterVolume при повышенной громкости пока не подтверждена.

## Выпуск

Готовый файл — `VoiceNormalizer.plugin.js`. Установка и описание возможностей находятся в [README](../README.md), правила сборки — в [инструкции разработки](../CONTRIBUTING.md). Версия закрепляется тегом `v1.3.0`; файл для установки распространяется через GitHub Releases.

Подача в каталог BetterDiscord — отдельный этап.

## Ограничения

Регулировка использует статистику Discord, поэтому не гарантирует мгновенное подавление начала пика. Определение речи приблизительное и зависит от внутренних API Discord. Восстановление исходной громкости после аварийного завершения приложения не гарантируется.

## После 1.3.0

Исправления по обратной связи и совместимость с обновлениями Discord. Возможные отдельные задачи — восстановление после сбоя и проверка совместной работы с BetterVolume.
