# Дорожная карта VoiceNormalizer

Текущий этап — **проверка надёжности перед стабильным выпуском**. Основной набор функций MVP реализован; добавление новых функций не является условием выхода в stable.

| --- | --- | --- |
| 1.0–1.1 | Выравнивание речи, SSRC, фильтрация коротких событий | Реализовано |
| 1.2.0 | Глобальные профили и ручные параметры | Принято в main через PR #3 |

## Что уже готово

- Выбор участников по user ID, сохранение после перезапуска, возобновление после смены канала и возвращения человека.
- Обработка всех в текущем голосовом канале, включая новых участников; сохраняемые исключения и отдельный ручной список.
- Усиление тихой речи и приглушение громкой либо режим только приглушения.
- Глобальные и индивидуальные профили, ручные параметры, наследование общих настроек, сброс обучения.
- Понятные статусы, стабильные карточки участников, кнопки профилей и свёрнутые технические настройки.
- Русский/английский интерфейс и короткие README на двух языках.
- Воспроизводимая сборка, проверки оформления/линтера и регрессионные тесты готового файла.

## Проверка кода в beta.2

Архитектура уже разделяет аудиорасчёт, определение активности, профили, пользовательские настройки, переводы и интерфейс. Полное переписывание перед stable не требуется.

Исправления по результатам просмотра:

- Запрос статистики ограничен по времени и отменяется локально при остановке. Поздний ответ не меняет громкость и не освобождает слот запроса новой сессии.
- Можно восстановить прочитанную исходную громкость выше внутреннего предела 200, не разрешая произвольное повышение лимита. Для такой базы дополнительное усиление сверх неё не выполняется. Полная совместимость с BetterVolume всё ещё требует прослушивания.
- Порог изменения и допуски учитывают очень маленькую исходную громкость; ручное значение 0 не отменяется восстановлением после теста.
- Панель использует один список участников на обновление вместо повторного чтения для каждой карточки.

Номер beta не является подтверждением прохождения ручных сценариев. Результаты автопроверок фиксируются в PR; тесты запускаются на завершённой сборке, а не после каждой функции.

## Условия выхода в 1.3.0 stable

- [ ] Провести 2–3 обычных голосовых сессии с несколькими участниками: тихая речь, обычная речь, громкая речь, паузы. Убедиться, что громкость не «качается» и фон не становится навязчивым.
- [ ] В реальном Discord проверить выход/вход в канал, смену канала, возвращение участника и перезапуск приложения: выбор сохраняется, обработка возобновляется.
- [ ] Проверить режим для всех, появление нового человека, исключение и возврат к ручному списку.
- [ ] Проверить ручной ползунок, значение 0, выключение плагина и сброс обучения: исходная или новая ручная громкость сохраняется корректно.
- [ ] Проверить BetterVolume при обычной и повышенной исходной громкости. Автотесты с имитацией Discord не заменяют эту проверку.
- [ ] Проверить профили, режим только приглушения, русский/английский язык и отсутствие закрытия окна/скачков карточек.
- [ ] На финальном кандидате выполнить сборку, проверку соответствия исходникам, линтер и один полный набор тестов. После изменения кода повторить проверку готового файла.
- [ ] Принять PR #5, проверить совпадение файла в main с кандидатом, обновить версию до 1.3.0 и создать релиз с одним файлом VoiceNormalizer.plugin.js.

При необходимости промежуточной проверки можно выпустить `1.3.0-rc.1`; отдельные этапы 1.4 и 1.5 только ради старого плана не нужны.

## Известные ограничения

- Это регулировка по статистике Discord, не сэмпловый лимитер: начало резкого пика может пройти до уменьшения громкости.
- Определение речи по статистике приблизительное. Внутренние API Discord могут изменяться.
- После аварийного завершения Discord восстановление исходной громкости не гарантируется. Восстановление после сбоя требует отдельного решения; сейчас оно не заявляется как функция.

## После stable

Исправления по обратной связи и совместимость с обновлениями Discord. Улучшение поведения после аварийного завершения — отдельная возможная доработка. Эквалайзер, запись звука, собственное шумоподавление и DSP-лимитер в текущий MVP не входят.

Публикация в каталоге BetterDiscord — отдельный организационный шаг. Она не определяет номер стабильной версии и не должна раздувать пользовательский README.
