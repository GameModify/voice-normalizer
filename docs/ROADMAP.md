# Дорожная карта

Стабильная опубликованная версия — **1.3.0**. Текущая рабочая сборка — **1.4.0-beta.1** для проверки новой модели громкости.

## 1.4: комфортная громкость пользователя

- Отдельная коррекция воспроизведения без изменения пользовательского ползунка.
- Первичное обучение обычной речи каждого участника вместо общей абсолютной цели RTP.
- Усиление тихих фраз, относительная защита от громких и ускоренное восстановление после приглушения.
- Сохранение обучения при ручной смене громкости, в паузах и при пропуске статистики.
- Защита от перехода на старый способ изменения ползунка при недоступном аудиоинтерфейсе.

## Проверка

Локальный стенд проверяет раздельность пользовательских настроек и воспроизведения, калибровку, тихую речь, громкие фрагменты, паузы, mute, смену соединения и снятие всех обработчиков.

После готовой сборки — установка в Discord. Необходимы подтверждение native API в Discord, оценка реального усиления и проверка совместимости с BetterVolume. Стабильный релиз 1.3.0 не заменяется до подтверждения новой версии.

## После проверки

Исправления по прослушиванию, затем стабильный выпуск 1.4. Возможные дальнейшие задачи — восстановление после аварийного завершения Discord и совместимость с обновлениями его внутренних API.
