# Разработка

Исходники находятся в `src/`, готовый файл — `VoiceNormalizer.plugin.js`. Изменяйте исходники, затем пересобирайте плагин. Для разработки нужен Node.js 22 или новее.

## Проверка готовой версии

После `npm ci` выполните:

```sh
npm run build
npm run check
npm test
```

Полный набор проверок запускается на завершённой сборке. Для изменений звука или интерфейса нужна также ручная проверка в Discord.

Работайте в отдельной ветке от `main`. В PR опишите изменение поведения и проверку. После принятия PR удалите завершённую ветку.

Не добавляйте в репозиторий личную конфигурацию Discord, секреты, дампы звонков, `node_modules/` и резервные копии.

## Релиз

После готовой сборки выполните `npm run package:release`. Команда проверяет соответствие исходникам, запускает готовый файл в изолированном окружении с пустыми настройками и проверяет сохранение выбора между экземплярами. Затем собирает в `dist/voice-normalizer-<версия>/` ровно три вложения: `VoiceNormalizer.plugin.js`, `LICENSE` и `SHA256SUMS.txt`. Для установки нужен только файл плагина; условия MIT включены также в него.

Публикуйте тег `v<версия>` на проверенный коммит с совпадающей версией в `package.json` и метаданных плагина. Заметки к выпуску хранятся в `docs/releases/`. После публикации скачайте вложения и сверьте SHA-256. Опубликованные файлы и существующие теги не заменяются; исправления выпускаются новой версией. Архивы Source code создаёт GitHub из тега.
